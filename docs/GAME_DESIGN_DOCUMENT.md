# Kanaka 游戏设计文档

> 状态：GDD Draft v1
> 平台：iPhone / iPad
> 类型：叙事型 Classic Nonogram + 拼豆蓝图收藏与制作工具

## 1. 产品愿景

Kanaka 将逻辑解谜和拼豆制作连接在同一产品中。玩家既可以通过 Nonogram 亲手恢复作品，也可以把 App 当作经过策展的拼豆图纸工坊。

产品不是两个 App，而是**同一个 App 内两条平等的使用路径**。首次启动先建立“长夜”和文明修复署的共同故事，再通过一局可明确跳过的 `5×5` 共同教学解释 Nonogram。用户完成或跳过教学后，才开放工坊并选择初始路径：

- **学徒成长 / 修复室路径**：以见习修复师身份学习 Nonogram、推进故事并成长。
- **专业画师 / 拼豆工坊路径**：以专业制作者身份浏览蓝图、准备材料并导出制作文件。

该选择只决定默认落点和教学顺序，不是永久职业，也不会锁定功能。用户进入共同修复室后，可以随时在两条路径间切换。

## 2. 目标用户

### 2.1 解谜玩家

需求：逻辑推理、难度成长、安静体验、完成反馈和收藏进度。

### 2.2 拼豆制作者

需求：快速找到漂亮的大图、准确色号与数量、可打印图纸，不希望被强迫先解几十关。

### 2.3 收藏与叙事玩家

需求：修复世界观、作品档案、环境叙事和视觉恢复过程。

三类用户使用同一作品内容，但入口、节奏与目标不同。

## 3. 单 App 双路径设计

### 3.1 主信息架构

```text
启动
→ 共同故事：长夜 / 文明修复署 / 保存图像的任务
→ 5×5 共同修复教学
   ├─ 完成教学
   └─ 明确选择跳过
→ 开放拼豆工坊与平等路径选择
   ├─ 学徒成长：继续进入修复工作台
   └─ 专业画师：进入拼豆工坊 / 蓝图与材料教学
→ 汇入共同修复室主空间
   ├─ 修复工作台
   │  ├─ 章节
   │  ├─ 作品
   │  ├─ Fragment 地图
   │  └─ Nonogram 棋盘
   ├─ 拼豆工坊
   │  ├─ 蓝图库
   │  ├─ 作品预览
   │  ├─ 材料清单
   │  ├─ 打印/导出
   │  └─ 蓝图解锁
   ├─ 收藏回廊
   └─ 设置/无障碍/购买管理
```

建议使用修复室空间中的两个明确入口，而不是让用户进入设置切换“游戏模式”。移动端可采用底部导航或工作台左右两个区域：

- 工作台图标：修复。
- 图纸柜图标：工坊。

### 3.2 共享内容

两条路径使用同一个 `Artwork`：

- 完整作品图。
- 受损作品图。
- Fragment 列表。
- Nonogram 谜题。
- 拼豆蓝图。
- 材料清单。
- 档案文字。
- 权利与来源记录。

不复制作品、不维护两套内容 ID，也不分别下载素材。

### 3.3 分离的状态

以下状态必须分开保存：

#### Puzzle Progress

- `notStarted`
- `inProgress`
- `completed`
- `completedWithoutHints`

#### Story Restoration

- 未发现
- 已扫描
- 局部修复
- 完整修复

只由实际解谜推进。

#### Blueprint Access

- `preview`：可看完成效果、尺寸和颜色概况。
- `earned`：通过完成作品获得。
- `purchased`：通过工坊权益直接获得。
- `earnedAndPurchased`：先购买后又亲手完成。

#### Entitlement

- 免费样本。
- 完整游戏章节权益。
- 工坊蓝图包权益。
- 已恢复购买。

### 3.4 核心访问规则

```text
artworkSolved = coreFragments.allSatisfy(\.isCompleted)
canUseBlueprint = artworkSolved || blueprintPackPurchased
storyCompleted = artworkSolved
hasRestorerSeal = artworkSolved
```

这里的 `artworkSolved` 指该作品关卡的全部核心 Fragment 已完成；完成单个局部 Nonogram 不会解锁完整大图。

直接购买蓝图：

- 可以查看高清图纸、色号、数量和导出文件。
- 不把谜题标为完成。
- 不推进章节。
- 不授予“亲手修复”印章。
- 不跳过修复动画和档案事件。
- 以后仍可正常游玩；完成后升级为亲手修复状态。

这不是付费跳关，而是另一种获得制作资产的路径。

## 4. 核心游戏循环

1. 在修复室选择一个作品关卡；每个作品关卡对应一幅受损大图。
2. Fragment 地图展示该作品关卡包含的多张局部图，并区分核心与可选 Fragment。
3. 选择一个 Fragment；这一张局部图对应一个 Nonogram 谜题。
4. 根据行列 clues 填色与排除。
5. 完成后将二值答案转为彩色修复 fragment。
6. Fragment 融回大型作品，只恢复对应的一小块内容。
7. 更新核心修复进度、档案完成度和故事状态。
8. 完成全部核心 Fragment 后，作品完整修复，并获得完整大图拼豆制作包。

## 5. 拼豆工坊循环

1. 浏览完整作品的低风险预览。
2. 查看尺寸、颜色数、总豆数、底板数量和预计工时。
3. 选择已经获得的蓝图，或直接解锁作品/主题蓝图包。
4. 选择拼豆品牌或色板映射（V1 可只支持项目标准色板）。
5. 查看分页网格、色号与数量。
6. 导出 PDF、PNG 和材料清单。
7. 可回到修复室挑战对应作品，获得亲手修复印章。

### 5.1 预览与奖励边界

所有用户都可以看到：

- 完整作品的展示预览。
- 成品模拟效果。
- 画布尺寸。
- 大致颜色数和难度。

未获得蓝图时不可访问：

- 可逐格复制的高清网格。
- 完整色号对应关系。
- 精确逐色数量。
- 分页打印文件。
- 无水印高分辨率图纸。

展示图负责帮助选择；可制作蓝图才是奖励。

## 6. 作品关卡、Fragment 与大型作品

### 6.1 内容层级

Kanaka 中“关卡”默认指一个**作品关卡（Artwork Case）**。一个作品关卡围绕一幅待修复大图，由多张局部图组成：

```text
章节
└─ 作品关卡：一幅受损大图 + 一份完整蓝图奖励
   ├─ 核心 Fragment：一张局部图 + 一个 Nonogram
   ├─ 核心 Fragment：一张局部图 + 一个 Nonogram
   ├─ 核心 Fragment：一张局部图 + 一个 Nonogram
   └─ 可选 Fragment：一张局部图 + 一个 Nonogram
```

因此：

- 一张小图不是一个完整作品关卡，而是作品关卡中的一个 Fragment。
- 每个 Fragment 只对应一个局部 Nonogram 谜题。
- 每次完成谜题只修复大图的一小块。
- 完成全部核心 Fragment 后，才获得完整大图蓝图和亲手修复印章。
- 可选 Fragment 不阻挡完整蓝图，只影响档案完成度和额外奖励。

### 6.2 不用简单小图承担全部创意

`5×5`、`10×10` 谜题不必各自成为一个普通小动物或小物件。它们可以是大型作品中的有意义区域：

- 眼睛和面部轮廓。
- 手、花、珠宝和服饰纹样。
- 建筑窗户与天际线。
- 动物头部和标志姿态。
- 强烈的明暗形状。

完成后的彩色 fragment 可以远比解谜时的二值轮廓丰富。

### 6.3 Fragment 选择原则

- 选择有语义、有轮廓的局部。
- 不机械等分大图。
- 相邻 fragment 可以重叠少量视觉区域，但答案格不重复计入进度。
- 小尺寸必须人工重绘，不能只做缩放。
- 每个局部完成后，大画变化应清晰可见。
- 最后一块应是视觉或叙事焦点。

### 6.4 小图的独立价值

一部分简单关卡可以奖励适合真实制作的小型图纸：

- 钥匙扣
- 冰箱贴
- 杯垫
- 手机挂件
- 徽章
- 大作品中的标志性纹样

它们不是大型作品的廉价缩小版，而是用途不同的制作物。

## 7. 难度体系

| 损毁等级 | 典型尺寸 | 目标时长 | 用途 |
|---|---:|---:|---|
| 表面划痕 | 5×5 | 1–3 分钟 | 教学 |
| 边角破损 | 10×10 | 3–6 分钟 | 短局 |
| 颜料脱落 | 15×15 | 7–15 分钟 | 标准关卡 |
| 烟熏烧蚀 | 20×20 | 15–30 分钟 | 高级关卡 |
| 画布碎裂 | 25×25 | 25–45 分钟 | 专家关卡 |
| 失落名作 | 多个 fragment | 跨多个谜题 | 收藏目标 |

尺寸只是基础指标。最终难度结合：

- Solver 推理步骤。
- 线索信息量。
- 连续段数量。
- 强制填格比例。
- 是否存在猜测分支。
- 玩家实测耗时、错误和提示。

V1 所有正式关卡必须唯一解并可纯逻辑完成。

## 8. 操作规则

### 8.1 格子状态

- Unknown：未知。
- Filled：确认需要修复。
- Excluded：确认不填。

### 8.2 工具

- 修复笔：Filled。
- 排除标记：Excluded。
- 橡皮：Unknown。
- Undo / Redo。
- Hint。
- Zoom / Pan。

### 8.3 手势

- 单击操作一个格子。
- 连续拖动按首格动作批量处理。
- 达到阈值后锁定主要行/列，避免斜向误触。
- 两指只缩放和平移，不改变格子。
- 一次拖动形成一个 Undo transaction。
- iPad 可支持 Apple Pencil，但不将其作为必需输入。

## 9. 提示与失败

- 不使用生命值或等待恢复。
- 即时错误提示可关闭。
- Undo/Redo 不限次数。
- 提示等级：指出可推理行列 → 确定一个格 → 解释一步逻辑。
- 提示不作为付费消耗品。
- 记录无提示完成，但不给有提示玩家惩罚性失败。
- 禅模式可以关闭计时和错误反馈。

## 10. 奖励结构

### 10.1 单个 Fragment 谜题奖励

- 对应局部恢复颜色。
- 作品关卡的核心修复进度或档案完成度提高。
- 可能解锁档案文字、旧照片或当前 fragment 的小型图纸预览。
- 不直接发放完整大图蓝图。

### 10.2 作品关卡奖励

完成该作品关卡的全部核心 Fragment 后获得：

- 完整大型拼豆蓝图。
- 色号与逐色数量。
- 底板布局与完成尺寸。
- 分页打印 PDF。
- PNG 网格图。
- 材料清单。
- “亲手修复”档案印章。

### 10.3 购买后的区别

购买者立即获得蓝图制作能力，但档案中显示“馆藏授权”；实际完成全部核心 Fragment 后更新为“亲手修复”。购买不降低后续游玩的价值。

## 11. 商业模式

### 11.1 推荐 V1 结构

同一个免费 App：

1. **免费序章**：教学、若干局部 Nonogram 谜题和一个完整作品关卡闭环。
2. **完整修复版**：一次性非消耗型内购，开放全部首发谜题；蓝图通过完成作品获得。
3. **工坊蓝图权益**：让只想制作的用户立即获得相应蓝图。可以按首发全库或主题包出售。
4. 已购买完整修复版的用户可以购买工坊升级权益，避免重复购买相同功能。

具体 SKU 数量和价格必须在垂直切片用户测试后决定。首发应控制在少量、容易解释的选择，避免每张图一个商品造成管理和购买疲劳。

### 11.2 不采用

- 强制广告。
- 订阅作为首发核心模式。
- 体力。
- 提示币。
- 随机蓝图或抽卡。
- 付费自动完成谜题。

## 12. 首次体验

目标：先让用户理解共同故事和 Nonogram 的基本操作，再在不分主次的情况下选择初始路径；5 分钟内理解两条路径共享同一文明保存目标。

1. 播放可跳过的 8 秒开场，介绍长夜后的博物馆。
2. 档案 AI 说明文明修复署和“保存人类曾经看见过的图像”这一共同任务。
3. 进入约 60–90 秒的 `5×5` 共同教学：无计时、无失败惩罚，逐步解释 Filled、Excluded 和行列线索。
4. 教学提供清楚可见的“跳过教学”；用户完成或明确跳过后，才开放拼豆工坊与路径选择。教学之后可从帮助中重玩。
5. 平等展示“学徒成长”和“专业画师”，并明确之后可以随时切换。
6. 学徒路径继续进入修复工作台；专业画师路径进入工坊教学，查看作品预览、色号、材料和蓝图权益，具体免费样本范围由 A-003 决定。
7. 任一路径引导结束后进入共同修复室，并突出另一工作区入口。
8. 用户切换路径时保留全部作品、权益和进度。

共同 `5×5` 教学不归属于学徒路径，也不代表学徒路径层级更高。它只负责避免不了解 Nonogram 的用户误选后立即流失。

## 13. 页面清单

- 启动与共同故事开场。
- 可完成或明确跳过的 `5×5` 共同教学。
- 平等路径选择：学徒成长 / 专业画师。
- 修复室主空间。
- 章节/档案柜。
- 作品详情与 fragment 地图。
- Nonogram 棋盘。
- 完成与融回动画。
- 拼豆工坊蓝图库。
- 蓝图详情、材料清单和导出。
- 蓝图权益页。
- 收藏回廊和档案卡。
- 设置、无障碍、隐私、制作人员、恢复购买。

## 14. 无障碍

- 非棋盘 UI 支持 Dynamic Type。
- Filled、Excluded、Unknown 不只靠颜色区分。
- 足够对比度和深色界面。
- Reduce Motion 将复原动画替换为淡入或即时结果。
- VoiceOver 可完成章节、工坊、购买、导出和设置。
- 棋盘提供逐行/逐格导航和自定义操作。
- 声音与触觉不是唯一反馈。
- 支持 Voice Control、Switch Control 和 Full Keyboard Access 的主要路径。

## 15. 首发内容建议

- 3 个章节。
- 首发局部 Nonogram 谜题数量待 A-005 对齐；当前 `100–150` 仅为规划占位，不代表作品关卡数量。
- 3–5 个大型作品关卡，每个作品关卡包含多个 Fragment。
- 免费序章包含一个完整作品关卡闭环；具体 Fragment 谜题数待 A-005 对齐。
- 10 个用于首轮技术验证的代表关卡。
- 30% 短局、45% 标准、20% 高级、5% 专家。
- 每幅大型作品至少提供一个制作预览和一个完整导出包。

## 16. 成功指标

### 产品

- 教学完成率。
- 首幅作品完成率。
- 第 1、7、30 日留存。
- 修复室与工坊之间的切换比例。
- 解谜获得蓝图与直接解锁蓝图的比例。
- 蓝图导出率。

### 质量

- 崩溃率和 hang。
- 存档丢失为零容忍事件。
- 多解/无解正式关卡为零。
- StoreKit 购买与恢复成功率。
- 20×20、25×25 的误触和放弃率。

## 17. 待验证问题

- 用户更喜欢“修复室/拼豆工坊”还是更直接的“解谜/图纸”命名。
- 工坊用户最需要 PDF、PNG、CSV 中的哪些格式。
- 蓝图按单幅、主题包还是全库销售最易理解。
- 完成单个 fragment 是否应该提供可制作的小图纸。
- 25×25 在小屏 iPhone 上是否需要限制或默认横屏。
- 购买蓝图后继续解谜的动机是否足够，需要何种非物质奖励。
